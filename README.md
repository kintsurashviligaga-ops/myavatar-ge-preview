# MyAvatar.ge — Free Interface Preview

A backend-free, static visual preview of the MyAvatar.ge product direction. This project is intentionally safe to host for free before Vercel/Supabase billing is enabled.

## Includes

- MyAvatar rocket logo and electric blue/cyan brand system
- Studio workspace shell
- Prompt composer interaction
- Service cards for video, avatars, images, and music
- Responsive desktop/tablet/mobile layout
- No secrets, no database, no paid API calls

## Not included yet

Authentication, Supabase data, Stripe billing, AI generation, uploads, webhooks, and background jobs are intentionally disabled in this preview.
